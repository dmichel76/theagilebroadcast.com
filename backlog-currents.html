Backlog currents

Watch how items really move through a prioritised backlog: what climbs, what sinks, what never moves, and what skips the queue. Then see what that flow says about how your team really chooses work.

What files do I need?
Azure DevOps
  1. Make a query for your backlog items with State not Done or Closed, sorted by Backlog Priority.
  2. Columns: ID, Title, State, Backlog Priority.
  3. Export to CSV once a week or sprint. Put the date in the file name, e.g. backlog-2026-10-19.csv.
Jira
  1. Filter: project = ABC AND statusCategory != Done ORDER BY Rank.
  2. Export CSV with Issue key, Summary, Status. Row order is used as the rank.
  3. Same routine: one dated file per week or sprint.
One file with history
  1. Columns Date, ID, Title, State, Rank, one row per item per snapshot (e.g. from ADO Analytics).
  2. Keep just-started items (Active, Committed, In Progress) in the export so the page can tell started work from removed work.
