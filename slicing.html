Slicing game · 12 weeks · about 5 minutes

Slice it right

Same work, same team, same twelve weeks. You decide how to slice it and in what order. Then watch when the value actually arrives.

The brief

“As a user, I want to be able to cancel an order by myself”

On this ecommerce platform, cancelling an order means calling the call centre. The business wants self-service cancellation on the website and the iOS and Android apps. You have 12 weeks. How would you slice it to deliver value early, and learn or reduce risk?

  1. 1. Write your slicesAdd a card for each slice and say what it is, like “Show on the website if an order can be cancelled”.
  2. 2. Size themGive each slice its effort in weeks and the value it adds every week once it’s live, on top of what’s already there. Zero is allowed.
  3. 3. Put them in orderDrag the cards. Slices are built one after the other, and value only lands when a slice ships.
  4. 4. Run the 12 weeksEffort is width, value is height. Red is time going by with nothing in customers’ hands.
Your plan

Slice the feature

Value is in points per week, added on top of earlier slices: all your slices together might add up to 10, “every customer can cancel online and the calls stop”. Drag a card by its ⋮⋮ handle to reorder (press and hold on a phone).
